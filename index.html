What Silent Failures We Catch & Fix

1. Hooks Pointing at Missing Scripts

When a hook command in .claude/settings.json references a missing path or uses a subshell while read loop, it fails open with exit code 0. The rule you thought was enforced is completely inactive.

2. Skills Missing Frontmatter Triggers

Claude matches tasks to skills using the YAML description: field. Skills committed without a trigger-phrased description never fire in real sessions.

3. Always-On Context Bloat in CLAUDE.md

A 2,500+ token CLAUDE.md burns 100,000+ input tokens per 40-turn session before a single source file is read. We slim always-on context under 500 tokens and extract workflows into on-demand skills.

4. Mechanical PreToolUse / PostToolUse Enforcement

We convert your prose rules ("Always run Pint/ESLint/pytest", "Never include watermark") into tested shell hooks wired to your actual repo linter and verified by an automated regression suite.
